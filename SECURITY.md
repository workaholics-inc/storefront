# Security policy

Please do not open a public issue for a security problem.

Report it privately through GitHub's [private vulnerability reporting](https://github.com/workaholics-inc/storefront/security/advisories/new) for this repository. Include what you found, how to reproduce it, and what you think the impact is. We will acknowledge the report, keep you updated, and credit you if you want to be credited.

This repository contains only the public website. It must never contain secrets: if you find a key, token or credential in the code or its history, report it the same way.
