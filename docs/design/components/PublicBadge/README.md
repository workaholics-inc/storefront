# PublicBadge

Marks what an owner chose to show to everyone; its counterpart marks the one exception, a members-only post inside a public project.

**Provide:** the item's `visibility` as returned by the platform.

**States:** Public («عمومی», `eye`, `bg-brand-soft text-link`, with a title explaining "Everyone can see this, not only members"); Members only («فقط اعضا», `lock`, outlined, `text-ink-muted`).

**Rules**
- Members-only is the default and is never labelled, except on a post inside a public project.
- Show Public next to the project title, on the project card, and in a post's head row when the post itself is public.
- The storefront shows a page publicly only when the platform says so; the badge reflects that answer and decides nothing.
