# FeedbackThread

One post and all its feedback: the post in full, then the feedback list filtered by All, Awaiting response or Answered, with the answer control opening in place for owners.

**Sections:** breadcrumbs (project › post) · the post · «بازخوردها» with its order stated («اول آن‌هایی که منتظر پاسخ‌اند، بعد به ترتیب زمان») · tabs without counts · FeedbackItems · aside: for owners, the answer rule and the 7-day window; for others, what good feedback looks like and the composer.

**Rules:** awaiting and overdue items come first, then answered ones by date. Tabs never show numbers. An owner answering one item never moves the page; the item updates in place and the giver is notified.
