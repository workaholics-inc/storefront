# Logo

The Workaholics mark (a blue W with an eye) and the lowercase Vazirmatn wordmark, with sizes, clear space and what never to do.

**Provide:** nothing. Use the inline SVG mark with fills from `color-logo`, `color-logo-eye` and `color-logo-pupil`, and the wordmark as live text (`font-extrabold`, 800, `-0.012em`, lowercase) in `text-ink`.

**Rules**
- Header: mark 22px tall, wordmark 21px, gap 0.55rem. The lockup sits at the inline start and never mirrors (`dir="ltr"` on the lockup).
- Mark alone at 24px and below (favicon, app icon). 16px is the minimum.
- Clear space: half the mark's height on every side.
- The vector trace in `assets/logos/` was drawn from the 150px original; the owner approved it on 2026-10-17, and it replaces the JPG. The outlined `wordmark-*.svg` and `lockup-*.svg` files are for places without the web font (social images, the README).
